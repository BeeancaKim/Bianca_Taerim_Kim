XML이란?

eXtensible Markup Language[1] 

인터넷 웹페이지를 만드는 HTML을 획기적으로 개선하여 만든 언어이다. 홈페이지 구축 기능, 검색 기능 등이 향상되었고, 웹 페이지의 추가와 작성이 편리해졌다.
  • XML은 현재 전자상거래 영역에서 가장 활발하게 쓰이고 있다.
  • 구조와 체계가 있기 때문에 정보를 정리하는 데에 효율적이다.
  • 위와 같은 이유로 데이터베이스 활용이 가능하다.


Q. Markup Language?

A. 마크업은 문서 내용 외에 문서에 추가되는 정보로, 마크업 언어는(Markup Language) 해당 정보를 표현하는 언어라고 할 수 있다. 이를테면, 글자 모양 등을 지정하는 것도 마크업에 해당한다. 이러한 마크업을 나타내는 것이 마크업 언어이다.

XML 문서

  • XML 문서는 크게 '선언'부와 '태그 및 데이터'를 나타내는 부분으로 나눌 수 있다. 그 예시는 다음과 같다.
<?xml version="1.0" encoding="utf-8"?>

<!-- XML 문서 예제 -->

<책장>
   <책 넘버="001">
      <저자>한강</저자>
      <제목>소년이 온다</제목>
      <종류>장편소설</종류>
      <출간일>2014-05-19</출간일>
      <요약>섬세한 감수성과 치밀한 문장으로 인간 존재의 본질을 탐구해온 작가 한강의 여섯번째 장편소설 『소년이 온다』가 출간되었다.</요약>
   </책>
</책장>


XSL 문서

XSL은 XML 문서에 적용할 수 있는 스타일시트로, 일종의 템플릿 및 겉으로 보이는 구조라고 이해할 수 있다. 즉 사용자에게 데이터를 어떻게 제공할 것인지 정의하여 디자인하는 것이다.
  • 다음은 XSL 문서의 예제이다.
<?xml version="1.0" encoding="utf-8"?>
<xsl:stylesheet version="1.0"
	xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

 <xsl:template match="/책장/책">
   <h3> 도서 목록 </h3>
   <h3> Title </h3>
   <xsl:apply-templates select="제목"/>
<p> </p>
   <h3> Author </h3>
   <xsl:apply-templates select="저자"/>
<p> </p>
   <h3> description </h3>
   <xsl:apply-templates select="요약"/>
<p> </p>
 </xsl:template>
 </xsl:stylesheet>
  • 단, IE가 아닌 브라우저의 경우, xsl 적용 xml의 접근을 막는 경우가 대다수이다. 따라서 템플릿 설정은 다양한 브라우저에서 모두 사용 가능한 CSS를 통해 함이 옳으나 본 페이지는 기초적인 부분을 다루고 있으므로 생략한다.

XSL

<?xml version="1.0" encoding="utf-8"?>
<xsl:stylesheet version="1.0"
	xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

 <xsl:template match="/논문목록/논문">
   <h3> 참고 논문 </h3>
   <xsl:apply-templates select="논문명"/>
<p> </p>
   <xsl:apply-templates select="저자"/>
 </xsl:template>

 <xsl:template match="논문명">
   <font size="3"> 논문명 : </font>
   <font color='black'><xsl:value-of select="."/></font>
 </xsl:template>

 <xsl:template match="저자">
   <font size="3"> 저자 이름 : </font>
   <font color='blue'><xsl:value-of select="."/></font>
 </xsl:template>


 </xsl:stylesheet>
