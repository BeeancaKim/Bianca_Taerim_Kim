문서 만들기

  • 입력하고 싶은 문서 제목을 검색하여, 없는 제목이라면 '빨간색으로 표시된 제목'을 눌러 그대로 작성한다.
섬네일을 만드는 중 오류 발생: 파일이 없음

단락 나누기

머리글

  • 머리글은 2단계부터 사용 가능.
    • 2단계 머리글: ==
    • 3단계 머리글: ===
    • 4단계 머리글: ====

줄 넘김

  • </br> 태그를 입력한다.
  • 엔터를 두 번 입력한다.


글자 모양

모양 설정

  • 이탤릭체: 문자열 양쪽에 2개의 작은 따옴표
  • 진한 글씨체: 문자열 양쪽에 3개의 작은 따옴표
  • 진한 이탤릭체: 문자열 양쪽에 5개의 작은 따옴표
텍스트 결과 
''이탤릭체''</br>'''진한 글씨체'''</br>'''''진한 이탤릭체'''''
 이탤릭체
진한 글씨체
진한 이탤릭체


색상 설정

  • <font color="컬러코드"> 적용 범위의 글 </font>
  • <span style="color:컬러코드"> 적용 범위의 글 </span>
텍스트 결과 
<font color="red"> 빨간색 </font>
<font color="navy"> 남색 </font>
 빨간색
남색


글 정렬

  • 글자의 정렬은 <div style="text-align:속성값"> 입력 내용 </div> 사용
  • 사용 가능한 속성 값
    • 왼쪽정렬: left
    • 가운데정렬: center
    • 오른쪽정렬: right
    • 왼쪽과 오른쪽 열에 맞추어 정렬: justify

목록 생성

번호 있는 목록

  • # 기호를 사용하여 생성 가능.
  • #을 많이 사용할수록 더 깊은 단계.
  • 중간에 텍스트가 들어가면 번호가 새로 시작됨.
텍스트 결과 
# 1번
## 1.(2)-1
## 1.(2)-2
## 1.(2)-3
### 1.(3)-1
### 1.(3)-2
# 2번
# 3번
텍스트 삽입 시에는
# 4번 형성 불가
  1. 1번
    1. 1.(2)-1
    2. 1.(2)-2
    3. 1.(2)-3
      1. 1.(3)-1
      2. 1.(3)-2
  2. 2번
  3. 3번

텍스트 삽입 시에는

  1. 4번 형성 불가

번호 없는 목록

  • * 기호를 사용하여 생성 가능.
  • *을 많이 사용할수록 더 깊은 단계.
텍스트 결과 
* 1단계 
** 2단계 
*** 3단계
  • 1단계
    • 2단계
      • 3단계


링크 설정

문서 내부 링크

  • 문서의 제목 양쪽에 [[문서 제목 ]]과 같이 대괄호 두 개를 씌워 링크.
  • 존재하는 문서만 링크 가능.
  • | 기호를 사용하여 링크 제목 설정 가능.
  • # 기호를 사용하여 특정 단락 링크 가능.
텍스트 결과 
[[프로젝트 목록]]
 프로젝트 목록 
[[프로젝트 목록|링크 예제]]
 링크 예제 
[[프로젝트 목록#프로젝트 목록|단락 예제]]
 단락 예제

문서 외부 링크

  • 외부 사이트 링크는 [URL]과 같이 대괄호를 한 번만 사용한다.
  • URL 뒤 띄어쓰기를 한 번 하고 제목을 입력할 수 있다.
    • 제목이 없는 링크: [http://.....url....]
    • 제목이 부여된 링크: [http://.....url.... 제목]

그림 삽입

  • '파일 올리기' 항목에서 해당 사진을 업로드한 후, 정확한 이름을 [[파일:파일이름(확장자포함)]]에 입력한다.
텍스트 결과 
[[파일: KHDHlogo.png]]
 
크기 조절: [[파일: KHDHlogo.png|100px]]
 
설명 삽입(마우스 올려놓았을 때): [[파일: KHDHlogo.png|100px|경희대학교 디지털 인문학]]
 
위치 정렬: [[파일: KHDHlogo.png|100px|center|경희대학교 디지털 인문학]]
 
섬네일 방식: [[파일: KHDHlogo.png|100px|섬네일|경희대학교 디지털 인문학]]

지도 삽입

  • 다음 텍스트를 그대로 복사하여 쓰되, 위도와 경도가 들어간 항목은 모두 본인이 원하는 위치로 수정하여 줍니다. 총 4개를 수정해 주어야 합니다.
  • '//위치 텍스트를 수정하는 부분입니다'의 한글 부분은 본인이 원하는 텍스트로 변경 가능합니다. 다음 지도에서 '경희대학교'로 표시되는 부분입니다.
텍스트 결과

<head>
	<meta charset="utf-8"/>
	<title>Kakao 지도 시작하기</title>
</head>
<body>
	<div id="map" style="width:500px;height:400px;"></div>
	<script type="text/javascript" src="//dapi.kakao.com/v2/maps/sdk.js?appkey=1ed57cd25061cfcd716290112dfbc868"></script>
	<script>
		var container = document.getElementById('map');
		var options = {
			center: new kakao.maps.LatLng(37.596628, 127.052718),
			level: 3
		};

		var map = new kakao.maps.Map(container, options);
// 마커가 표시될 위치입니다 
var markerPosition  = new kakao.maps.LatLng(37.596628, 127.052718); 

// 마커를 생성합니다
var marker = new kakao.maps.Marker({
    position: markerPosition
});

// 마커가 지도 위에 표시되도록 설정합니다
marker.setMap(map);


//위치 텍스트를 수정하는 부분입니다
var iwContent = '<div style="padding:5px;">경희대학교 서울캠퍼스<br><a href="https://map.kakao.com/link/map/경희대학교,37.596628, 127.052718" style="color:blue" target="_blank">큰지도보기</a></div>', // 인포윈도우에 표출될 내용으로 HTML 문자열이나 document element가 가능합니다
    iwPosition = new kakao.maps.LatLng(37.596628, 127.052718); //인포윈도우 표시 위치입니다

// 인포윈도우를 생성합니다
var infowindow = new kakao.maps.InfoWindow({
    position : iwPosition, 
    content : iwContent

// 마커 위에 인포윈도우를 표시합니다. 두번째 파라미터인 marker를 넣어주지 않으면 지도 위에 표시됩니다
infowindow.open(map, marker); 

</script>
