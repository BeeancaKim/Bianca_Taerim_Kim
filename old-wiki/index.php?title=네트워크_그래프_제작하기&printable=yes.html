네트워크 그래프 작성 도구: MakeGraph[1]

  • MakeGraph는 Vis.js의 Network Library를 활용한 네트워크 그래프 시각화 (Network Graph Visualization) 프로그램입니다.
  • MakeGraph를 사용하면 온톨로지 설계 방식으로 대상 세계를 시각화할 수 있습니다.
  • MakeGraph는 한국학중앙연구원 디지털인문학연구소(김현 교수)에서 인문정보학 교육 도구로 개발하였으며, 누구나 사용할 수 있습니다.
  • MakeGraph로 제작한 그래프를 다른 On-Line 또는 Off-Line저작물의 제작에 사용한 경우, 이를 다음과 같이 표시하여 주시면 감사하겠습니다.
"이 저작물상의 네트워크 그래프는 Vis.js 네트워크 라이브러리 (Copyright (C) 2010-2017 Almende B.V. )와 MakeGraph 온톨로지 스크립트 변환기 (Copyright (C) 2017-2018 디지털인문학연구소, AKS)로 제작하였습니다."

네트워크 그래프 다운로드

  • 프로그램 다운로드: MakeGraph

기본 사용법

  • Mygraph2018.zip 파일을 압축 해제하면 다음 파일이 있습니다. sample 1~4는 예제 파일이며, MakeGraph droplet 2018.bat 파일이 네트워크 그래프를 만들 때 사용할 파일입니다. 편하게 작업하기 위해서는 MakeGraph droplet 2018.bat 파일과 sample 1 폴더에 있는 예제1.lst를 작업 폴더에 꺼내 두는 것이 좋습니다. 확장자명을 정확하게 지켜 주세요.
  • 리스트를 올바르게 작성하여 MakeGraph droplet 2018.bat 파일 위에 드래그하면 htm 파일이 형성됩니다. 이를 웹으로 열면 시각화 그래프를 확인할 수 있습니다.
  • 윈도우 기반 프로그램이므로, 맥북 사용자는 부트캠프 등을 활용하여 윈도우 기반 OS에서 작동해 주시기 바랍니다. MacOS에서도 lst까지는 작성이 가능하나, 시각화 결과를 볼 수 없습니다.
섬네일을 만드는 중 오류 발생: 파일이 없음

리스트 작성법

  • 예제1.lst 파일을 '메모장' 등의 텍스트 편집 프로그램으로 열면 다음과 같이 열립니다.
#Project
h1 나의 첫번째 네트워크 그래프

#Class
사람	
동물	
음식	

#Relation
likes	
loves	
isCloseTo		

#Nodes
철수	사람	철수	sample1.htm#Cheol-su		
영이	사람	영이	sample1.htm#Yeong-i					
보미	동물	보미	null						
커피	음식	커피	sample1.htm#Coffee			
크림	음식	아이스크림	sample1.htm#IceCream	

#Links
철수	크림	likes
영이	커피	likes
영이	보미	isCloseTo
철수	영이	loves

#End


  • 다음 항목부터는 '띄어쓰기' 입력 시 오류가 발생합니다. 띄어쓰기는 Class, Relation, Nodes, Links를 작성할 때 순서를 표시하는 데에만 사용됩니다. 텍스트상 띄어쓰기가 필요한 부분에는 '_'를 삽입해 주세요.
예시: 고전문학과_문화콘텐츠

#Project

  • 프로젝트 이름을 자유롭게 작성합니다.
  • 'h1'은 1에서 7까지사용 가능하며, 문자 크기가 지정됩니다.

#Class

  • 범주 항목입니다.
  • 'Class'는 간단하게 '큰 분류 체계'를 의미하나, 구체적인 개념은 추가적인 이해가 필요합니다.

#Relation

  • 노드 사이의 관계성입니다.
  • 각 Class에 속하는 Node들이 맺는 관계이나, 구체적인 개념은 추가적인 이해가 필요합니다.

#Nodes

  • Class에 해당하는 세부적인 노드입니다.
  • 차례대로 노드 식별자(Domain), 범주(Class), 노드 레이블입니다.
  • 노드 식별자는 각 개체의 명칭이므로 중복되는 이름이 있어서는 안 됩니다.
  • 노드 레이블은 시각화된 그래프에 표시되는 이름입니다.
  • 'sample1.htm#Yeong-i'과 같은 네 번째 항목은 노드를 클릭할 시 이동할 수 있는 URL입니다. null로 지정하면 이동하지 않습니다.

#Links

  • 노드를 이어 주는 링크입니다.
  • 위에서 정의한 관계를 사용하여 각 노드를 이어 줄 수 있습니다.
  • 차례대로 노드 식별자 1, 노드 식별자 2, 노드 사이 관계성입니다.


리스트 응용

위 항목을 이용하여 리스트를 작성하였다면, 노드 모양과 화살표 모양을 지정해 줄 수 있습니다. 노드 모양과 화살표 모양은 Class와 Relation 항목에서 작동합니다.


노드 모양 지정

  • #Class에서 노드의 색상, 모양 등을 지정합니다. Class 명 뒤에 색깔과 모양을 각각 지정해 주면 됩니다.
# Class
사람 red circle
동물 blue box
  • 색상은 red, blue, green 등 다양하게 활용 가능합니다.
  • 모양은 box(사각형), circle(원), ellipse(타원), star(별), triangle(삼각형), square(정사각형), dot(점), text(문자열)이 있습니다.


  • #Relation에서 관계성의 다른 이름, 화살표 모양 등을 지정합니다. Relation 뒤에 다른 이름과 화살표 모양을 각각 지정해 주면 됩니다.
# Relation
likes 좋아한다 arrow
loves 사랑한다 both
  • 화살표의 모양: arrow(--->), inverse(<---), both(<-->), moving-arrows(->->), line(----) 중에서 선택할 수 있습니다.
  • Relation의 원래 명칭을 사용할지, 다른 이름을 사용할지는 0, 1, 2, 3을 통해 설정 가능합니다.
# Relation
likes 좋아한다 arrow 0
loves 사랑한다 both 1
    • 0: 관계성 이름이 보이지 않음.
    • 1: 관계성 이름이 보이며, 커서를 올려 둘 시 다른 이름이 보임.
    • 2: 다른 이름이 보이며, 커서를 올려 둘 시 원래 이름이 보임.
    • 3: 함께 표시됨.
